### 1.1 T2 は走行器の緑/赤では原理的に観測できない

T2 は**集計器そのもの**(`test()` の `fail++`)を壊す。壊れた集計器の下では
どんな門が落ちても `0 failed` と印字され exit 0 になる —— 走行器の色は無意味になる。
ゆえに T2 の門は**門の本文だけを別プロセスで撃って**実測した(`probe-t2.js`):

```
注入版 T2 に対する門: exit=1  AssertionError: 失敗を数える一行が消えている
実物に対する門:       exit=0  gate PASSED
```

**これは「変異を注入して走行器が赤くなるか」という測り方自体の底が抜ける場所である。**
この環で三度「無音ゼロ」が裏切られた理由の一端がここにある可能性がある。
