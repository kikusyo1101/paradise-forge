## 1. 第60条の審理 —— **二分では説き切れない**

### 1.1 条文が何と言っていたか(改める前)

第60条(c) は治療をこう述べていた:

> (c) **治療は閾値の調整ではなく、印を強めることである。** **弱い名には**限定詞の
> 不在を追加で要求し(`a|the|my|our|…` が前に無いこと)、倉の印には
> `rev-parse --show-toplevel` の突合を追加で要求する。
> **強い印とは、問いと同じ広さの答えを返す印である。**

**この文は印を「弱い/強い」の二値で語り、治療を「弱い側に条件を足す」と述べている。**

### 1.2 実装は三枝である(実測)

```js
function isReformSubject(d) {
  if (REFORM_ABSTRACT_RE.test(d)) return true;                                  // 枝1 無条件
  if (REFORM_STRONG_RE.test(d) && (BUILD_RE.test(d) || MEND_RE.test(d))) return true; // 枝2
  return REFORM_WEAK_RE.test(d) && BUILD_RE.test(d);                            // 枝3
}
```

**三枝であり、三枝それぞれに課す条件が違う。**

条文が「弱い名には限定詞の不在を追加で要求」とだけ書くと、**読み手は二つの誤読をする**:

1. **「強い名には何も追加しない」と読める。** それが F-1 そのものだった
   —— build 相は強い名を無条件に通し、tribunal の BLOCK を招いた。
2. **「抽象名」という第三の層が条文に存在しない。** 抽象名(`楽園`/`門`/`憲法`)は
   **無条件でよい**が、条文は「印を強めよ」としか言わないので、
   **抽象名にも条件を課す修理**(build 相の変異 M-5 が撃った形)が条文に照らして正当に見える。

### 1.3 裁定: **三分法に改める**(二分では説き切れない)

**二分で説き切れることを示せるか試みたが、できなかった。**

「抽象名は**最強の印**なので追加条件ゼロ、強い名は**中位**、弱い名は**最弱**」——
これを「強い印/弱い印」の二語で表そうとすると、**「強い印」が二つの意味を持つ**:

* 抽象名 = **追加条件を要しないほど強い印**
* 強い固有名 = **追加条件を要するが、弱い名より広い動詞集合を許せる印**(と build 相は考えた)

**同じ「強い」が「条件不要」と「条件必要」の両方を指してしまう。** これは
第60条(a) が「弱い印とは、**問いより狭い答えしか返す印**である」と定義したのと同じ精神で
**印の強さは二値ではなく順序である**と言うほかない。ゆえに三分法へ改めた。

### 1.4 足した条文 —— (f) 項
