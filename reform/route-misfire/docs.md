## 2. 新しい条 —— **要る**。第60条を起草する

### 判定の根拠: 既存の条は**どれもこの病を名指していない**

読んだ条: 第16条 / 第19条 / 第21条 / 第23条 / 第37条 / 第44条 / 第49条 / 第52条 / 第54条 / 第57条 / 第59条。

| 条 | 何を言っているか | なぜ足りないか |
|----|------------------|----------------|
| **第23条** | 楽園は己の法で己を改革する。(a) 楽園自身を名指す願いは他の推測より**先に** reform へ。(b) reform の道は `prove` 相を持つ。(c) 無主の相を許さない | **道を決める「名指し」がどれほど弱くてよいかを一言も言っていない。** 「先に走らせよ」とは言うが、「何をもって名指しと認めるか」を空白のまま残した。本走行の誤着はその空白から生まれた |
| **第49条** | 道が無ければ願いは最も近い嘘の道へ攫われる。産物の種別が道を決める | **道の在る/無いの話**である。道は 6 本とも在り、それでも誤着した。判定の**印の強さ**は射程外 |
| **第37条** | 不在は通過ではない。見なかったことを見たことにするな | HIGH-1 の**害**は説明する。だが**原因**(弱い印)は説明しない。しかも本走行は「skip を**声に出して**いたのに変異が生き残った」を実測した —— **第37条を守ってなお漏れた** |
| **第54条** | 免除の資格は名乗りではなく**住所**が決める。申告は入口にすぎず、裏付けが資格を与える | **最も近い。** だが射程は「**免除**の自己申告」に限られる。本走行の病は免除ではなく**同定**(これは倉か / これは engine の名か)であり、しかも**両方向に誤った**。第54条は片方向(緩すぎ)しか見ていない |
| **第21条** | 門は名を語る**全ての口**を見張れ | 口の**数**の話。印の**強さ**の話ではない |
| **第44条 / 第57条** | 呼ぶ者の居ない門は腐る / 修理は掟を広げるな | 門の**生死**と**広さ**。印の**強さ**は別軸 |
| **第59条** | 進捗は状態ではない。走る環は証拠を携えて鼓動せよ | 別主題 |

**結論**: 「印の強さは裁きの強さに釣り合わねばならない」という掟は、**楽園の法に存在しない**。
そして本走行はこの一つの病が**二つの無関係に見える場所**で同時に発症したことを実測した ——
語彙(`forge.js`)と倉の印(`workspace.js`)。**二箇所で同じ形なら、それは普遍である。**

### 二つの実測(条文の根拠)

**(A) 語彙 — 弱い名が両方向に誤った**
`conclave` `forge` `gauge` `workspace` は engine の名である。だが `gauge` は車の計器でもあり、
`workspace` は仕事机でもある。名の一致だけで裁いたので:
- 誤って reform へ: `車のアプリに gauge の表示を追加する`(創造物の願いを engine 改修と誤認)
- 誤って standard へ: `graph/forge.js の道選びを直す`(engine 改修をファイル名と見て剥ぎ落とした)
**同じ弱い印が、両方向に誤った。**
修理は印を強めること —— 強い名(26)と弱い名(14)を割り、弱い名は**限定詞の後読み**
(`a|the|my|our|…` が前に無いこと)を追加で要求する。

**(B) 倉の印 — 弱い印が両方向に誤った**
`git config --get remote.origin.url` は「**この道は倉の中に在るか**」しか答えない。
だが門はそれを「**この道は倉そのものか**」として使った。git は `.git` を親へ遡るので、
倉の子・孫・`.git` の中まで全てが「倉である」と名乗った。
- 誤って倉と認めた(緩すぎ): 子を指すと走査せず「✓ 流出なし」と**緑を騙った**
- 誤って倉でないと退けうる(固すぎ): 目印ファイルだけに頼れば、目印の無い clone を見逃す
修理は印を強めること —— `rev-parse --show-toplevel` の**突合**を要求する。

**(C) そして門自身が同じ病に罹っていた** —— これが本走行の最も重い発見である。
HIGH-1 の回帰の門 B-12 は、こう始まっていた:

```js
if (!fs.existsSync(REAL_VAULT)) H.skip(`本物の創造物の倉が無い: ${REAL_VAULT}`);
```

**「本物の倉がたまたまこの機械に在る」は弱い印である。** GitHub Actions の checkout に
兄弟倉は無い。ゆえに CI では B-12 は**永久に skip され**、HIGH-1 の再発を誰も捕まえない。
実測で、変異試験 8 件のうち **V1(toplevel 突合を消す)だけが生存した**。

**第37条は守られていた。** 門は黙らず、skip を**声に出して**いた。
それでも漏れた。**声に出す skip は、鳴らない門の免罪符ではない。**
門は対象が在るのを待つのではなく、**対象を自ら建てねばならない**。

修理(本相で実施): 門が倉の替え玉を自分で組む —— `git init` + `remote add origin`。
本物を見る断定は B-12b に分け、在れば撃ち、無ければ**そこだけ**退く。

実測(兄弟倉が一切無い複製 = CI を模す):
```
(a) 変異なし → ✓ B-12   abandoned-run: 29 passed, 0 failed, 2 skipped
(b) V1 変異  → ✗ B-12   abandoned-run: 28 passed, 1 failed, 2 skipped   RAW EXIT=1
      倉の内側 pomodoro が倉と名乗った — git が .git を親へ遡っている。
      isCreationsVault から rev-parse --show-toplevel での突合が消えていないか見よ
```

## 3. 第60条 草案(CONSTITUTION.md へ追記した本文)

```
60. **弱い印で裁く門は、強い印を要求しなければ両方向に誤る。**
    一つの病が、無関係に見える二箇所で同時に発症した — 語彙と倉の印である。

    (a) **弱い印とは、問いより狭い答えしか返さない印である。**
        `git config --get remote.origin.url` は「この道は倉の**中**に在るか」しか
        答えない。門はそれを「この道は倉**そのもの**か」として使った。git は
        `.git` を親方向に遡るから、倉の子・孫・`.git` の中まで全てが「倉である」と
        名乗った。engine の名も同じである — `gauge` は車の計器でもあり、
        `workspace` は仕事机でもある。**名は engine を指しうるが、engine を意味しない。**

    (b) **弱い印は片方向にではなく、両方向に誤る。** これが弱い印の見分け方である。
        `車のアプリに gauge の表示を追加する` は誤って reform へ攫われ、
        `graph/forge.js の道選びを直す` は誤って standard へ落ちた。
        倉の印も同じ — 子を倉と誤認して**緑を騙り**(第37条違反)、
        目印だけに頼れば目印の無い clone を見逃した。
        **一方向にしか誤らない印は、閾値がずれているだけである。
        両方向に誤る印は、印そのものが問いに足りていない。**

    (c) **治療は閾値の調整ではなく、印を強めることである。** 弱い名には限定詞の
        不在を追加で要求し(`a|the|my|our|…` が前に無いこと)、倉の印には
        `rev-parse --show-toplevel` の突合を追加で要求する。
        **強い印とは、問いと同じ広さの答えを返す印である。**

    (d) **弱い印を捨ててもならない。** 印 1 を消して目印ファイルだけにすれば、
        目印の無い clone を見逃す。強い名を弱い名と同じ扱いにすれば、
        `conclave.js に門を足す` が届かなくなる。**弱い印は、強い印と組んで初めて働く。**
        捨てる修理は第57条が咎める「運べなかった条件を黙って捨てる修理」である。

    (e) **門そのものが弱い印で自らの発火を決めてはならない。** これが最も重い。
        (a)〜(c) の回帰を守る門は、こう始まっていた —
        `if (!fs.existsSync(REAL_VAULT)) skip('本物の倉が無い')`。
        **「対象がたまたまこの機械に在る」は弱い印である。** CI の checkout に
        兄弟倉は無いので、門は CI で**永久に黙った**。実測: 変異 8 件のうち、
        この門だけが守るはずの一件 (`toplevel` の突合を消す) **だけが生存した**。

        第37条は守られていた — 門は黙らず、skip を声に出していた。**それでも漏れた。
        声に出す skip は、鳴らない門の免罪符ではない。** ゆえに:
        **門は対象が在るのを待つのではなく、対象を自ら建てよ。**
        倉が要るなら `git init` して印を打ち、替え玉を組め。実在を見る断定は
        別の門に分け、在れば撃ち、無ければ**その断定だけ**を名乗って退く。
        **一つの門が「在れば撃つ」と「必ず撃つ」を兼ねてはならない** —
        兼ねた門は、必ず弱い方へ落ちる。

    **これを強制する門**: `graph/forge.js` の `ENGINE_NAMES_STRONG` /
    `ENGINE_NAMES_WEAK` / `DETERMINER_LOOKBEHIND`(弱い名は限定詞の不在を要求する)と、
    `graph/workspace.js` の `isCreationsVault`(`rev-parse --show-toplevel` の突合)。
    回帰は `tests/counsel.test.js` が両方向の誤着を撃ち、
    `tests/abandoned-run.test.js` の `B-12` が**自ら組んだ替え玉の倉**に対して撃つ
    (`B-12b` が実在の倉を撃ち、無ければ声に出して退く)。
```
