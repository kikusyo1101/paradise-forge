REFORM_RE には紛れ語の表が **存在しない**(forge.js に REFORM_FALSE_FRIENDS は無い):
  grep -c "REFORM_FALSE_FRIENDS" graph/forge.js = 0
  isReformSubject の本体 = function isReformSubject(d) { return REFORM_RE.test(d); }
