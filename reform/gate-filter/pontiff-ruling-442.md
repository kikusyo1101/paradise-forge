## 裁定

**requirements.md / discover.md の「静的 442」は正しい。**
**prove.md の「443」も review.md の「441」も、どちらも誤りである。**
**`442 − 1 + 8 = 449` は「偶然正解している」のではなく、端から正しい。**

review.md が「次に門を足すと静かに間違える」と警告した危険は**存在しない**。
この節の指摘は**取り下げるべきである**。

## 実測(教主が自分の手で撃った)

数え方が三通りあり、そこが分かれ目である。

```
$ git show 59aa00a:tests/paradise.test.js > $LOCALAPPDATA/Temp/old.js

$ grep -c '^test(' $LOCALAPPDATA/Temp/old.js
441                                    ← 行頭の test( だけ(review はここで止まった)

$ grep -cE '^[[:space:]]*test\(' $LOCALAPPDATA/Temp/old.js
442                                    ← 字下げされた test( を含む(これが「静的な test の数」)
```

**差の 1 は `tests/paradise.test.js:2762`(改革前 2697 行)である。**

```js
for (const name of ['dashboard-count', 'dashboard-no-deps', 'dashboard-links',
  'dashboard-no-hardcode', 'dashboard-transport', 'dashboard-freshness',
  'dashboard-states', 'dashboard-run-panel']) {
  test(`dashboard-count 系: ${name} が緑 (G-01/02/04/06)`, () => {   ← ★ 字下げされている
```

**この一本はループの内側にあるので字下げされており、`^test(` には当たらない。**
そして**まさにこの一本こそが実行時に 8 本へ展開される当のもの**である。

ゆえに:

```
静的 442(= 行頭 441 + ループ内 1)
実行時 442 − 1 + 8 = 449   ✓ 実測の 449 と一致
```

改革後も同じ構造で検算が合う:

```
$ grep -cE '^[[:space:]]*test\(' tests/paradise.test.js
444                                    ← 静的(= 行頭 443 + ループ内 1)
444 − 1 + 8 = 451                       ✓ 実測の 451 と一致
```

## 二人の神官が同じ穴に落ちた

| 相 | 主張 | 用いた数え方 | 誤り |
|---|---|---|---|
| prove | 「実測は 443」 | 改革**後**の `^test(` | 母数が違う(改革後)+ 字下げを落とした |
| review | 「実測は 441。442 は誤り」 | 改革**前**の `^test(` | 字下げを落とした |

**二人とも `grep -c '^test('` を使い、ループ内の一本を数え落とした。**
そして皮肉なことに、**その数え落とした一本こそが「差 7」の話の主役**である。

review は「`442 − 1 + 8 = 449` は誤った値と存在しない補正が打ち消し合って偶然正解している」
と書いたが、事実は逆である。**`−1` は実在する補正**であり(字下げの一本を静的な数から引く)、
**`+8` はその一本の展開**である。式は端から正しい。

## 教訓(reflect 相へ)

**この一件自体が discover の制約10「名は実行時にしか確定しない」の実演である。**

discover はこう書いていた:

> ゆえに grep / AST で名前一覧を作る実装は**この 1 箇所だけ 7 本嘘をつく**。

そして **prove と review という後続の二相が、まさにその罠に自分から落ちた。**
しかも二人とも「先行文書が間違っている」と確信して報告してきた。

AC-07 / AC-08 が「静的解析実装を機械的に禁じる門」として置かれたのは正しかった。
**だが門が禁じたのは実装であって、人間(と神官)の数え方ではなかった。**

**具申**: reform 系の文書で「静的な test の数」を語るときは、
`grep -c '^test('` ではなく `grep -cE '^[[:space:]]*test\('` を用いること。
あるいは端的に、**静的な数を語らないこと** —— `--gate-list` が実行時の真値を 0.08 秒で返す。
